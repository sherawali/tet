# डिजिटल हल प्रश्न-पुस्तिका (HTML Examination Booklet)

`bank-v2` के **सत्यापित (verified)** paper-form से अपने-आप बनने वाली **single-file HTML**
परीक्षा पुस्तिका। कोई build step, कोई server, कोई dependency नहीं — फ़ाइल सीधे ब्राउज़र
(मोबाइल/डेस्कटॉप) में खुलती है और offline भी चलती है।

## बनाने का तरीका

```bash
python3 tools/v2/build_booklet_html.py                        # डिफ़ॉल्ट : utet-p1-2025-set-a
python3 tools/v2/build_booklet_html.py --form utet-p1-2024-set-d
python3 tools/v2/build_booklet_html.py --form utet-p1-2021-set-c --out /tmp/preview.html
```

Output → `docs/booklet/<form-id>.html` (और `index.html` जो नयी बनी फ़ाइल पर redirect करता है)।

## पुस्तिका में क्या-क्या है

- **आवरण पृष्ठ** — द्विभाषी मस्तहेड, OMR अनुक्रमांक ग्रिड, SET स्टाम्प, 3-स्तम्भ specs strip, amber निर्देश बॉक्स
- **अनुभाग विभाजक** — `भाग-1 … भाग-5` बैनर (प्रश्न क्रमांक सहित), गद्यांश/कविता के लिए stimulus card
- **प्रश्न कार्ड** — `Q.n` बैज, हिन्दी प्रश्न + अंग्रेज़ी अनुवाद, 4 विकल्प टाइल (हिन्दी + अंग्रेज़ी),
  विषय पिल, `+1.00 / -0.25` बैज, ⚑ बुकमार्क, 🚩 रिपोर्ट
- **स्टिकी CBT बार** — 3px progress bar, डिजिटल काउंटडाउन (5 मिनट से कम पर लाल pulsing), `A-/A+`, fullscreen, 🌙/☀️
- **बॉटम डॉक** — `📋 OMR [ x/150 ]` live काउंटर + `✓ हल / ⭕ शेष` chips, `जमा करें ➔`
- **OMR पैलेट (bottom sheet)** — 150 बबल, हल/शेष/चिह्नित फ़िल्टर, बबल पर टैप = उस प्रश्न पर smooth scroll
- **समीक्षा मोड** — `आपका उत्तर (सही/गलत)`, `✓ आयोग सही उत्तर`, 360° संदर्भ व्याख्या बॉक्स, स्कोरकार्ड + उत्तर-कुंजी
- **कीबोर्ड शॉर्टकट** — `1–4` विकल्प, `B` चिह्नित, `N/P` अगला/पिछला, `M` पैलेट, `Esc` बंद
- **प्रगति सुरक्षित** — उत्तर, बुकमार्क, समय, थीम, अक्षर-आकार सब `localStorage` में
- **प्रिंट फ्रेंडली** — Ctrl+P पर सिर्फ़ प्रश्न-पुस्तिका प्रिंट होती है

## ध्यान रखें

- **समय/अंकन** : पुस्तिका की डिफ़ॉल्ट स्किन अभ्यास हेतु `−0.25` ऋणात्मक अंकन दिखाती है;
  UTET की आधिकारिक परीक्षा में ऋणात्मक अंकन **नहीं** है — स्कोरकार्ड दोनों आँकड़े बताता है।
- **व्याख्या** : `bank-v2` में अभी किसी प्रश्न के साथ hand-written explanation नहीं जुड़ी है,
  इसलिए 360° बॉक्स verified appearance record से अपने आप बनता है (सही उत्तर, स्रोत, विकल्प तुलना)।
  जैसे ही बैंक में `explanation` फ़ील्ड जुड़ेगी, बॉक्स वही दिखाएगा।
- **मस्तहेड/स्किन** बदलना हो (जैसे UKPSC वाला शीर्षक) : `tools/v2/build_booklet_html.py` के ऊपर
  `SKIN` dict में सिर्फ़ शीर्षक/निर्देश बदलें — प्रश्न डेटा हमेशा `bank-v2` से ही आता है।
- `cdn/` generated है — इस स्क्रिप्ट का उससे कोई लेना-देना नहीं।
