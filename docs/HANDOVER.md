## 1 · प्रोजेक्ट एक नज़र में

| | |
|---|---|
| **क्या बना रहे हैं** | UTET + CTET के लिए Android मॉक-टेस्ट ऐप |
| **खास बात** | पुराने पेपरों के गणितीय विश्लेषण से बना **प्रायिकता मॉडल** — जो बताता है कौन-सा प्रश्न आने की कितनी संभावना है |

## 2 · ⭐ CSV बनाम JSON — पूरी सफ़ाई

### एक वाक्य में
> **CSV = इंसान जो लिखता है।  JSON = ऐप जो पढ़ता है।  दोनों git पर रहते हैं।**

### पूरी बात

```
┌─────────────────────────────────────────────────────────┐
│  content/q_cdp.csv          ← तुम यहाँ लिखते हो        │
│  (CSV, Excel में खुलता है)                              │
└──────────────────────┬──────────────────────────────────┘
                       │  git push करते ही
                       │  GitHub का रोबोट चलता है
                       ▼
┌─────────────────────────────────────────────────────────┐
│  cdn/packs/pack-0000-abc123.json   ← ऐप यहाँ से पढ़ता  │
│  (JSON, अपने-आप बनता है, कभी हाथ मत लगाओ)              │
└─────────────────────────────────────────────────────────┘
```

### तुलना

| | CSV (`content/`) | JSON (`cdn/`) |
|---|---|---|
| कौन बनाता है | **तुम / AI** | **रोबोट, अपने-आप** |
| कहाँ खुलता है | Excel, Google Sheets, Notepad | सिर्फ़ कोड में |
| हाथ से छूना है? | **हाँ, सिर्फ़ यही** | **नहीं, कभी नहीं** |
| एक गलती से क्या होता है | सिर्फ़ वो पंक्ति खराब | **पूरी फाइल टूट जाती है** |
| git पर दिखता है | 1 प्रश्न = 1 लाइन | पूरी फाइल बदली हुई |
| हिन्दी लिखना | आसान | `\"` `\n` का झंझट |

### 🔑 याद रखने वाली बात
**तुम्हें JSON कभी नहीं छूना है। बिल्कुल कभी नहीं।** अगर कोई AI तुमसे कहे "यह JSON फाइल बदल दो" — मना कर दो। सिर्फ़ CSV।

## 3 · CSV कैसा दिखता है

### कॉलम (ठीक इसी क्रम में)

```
exams,section,topic,difficulty,pid,pseq,p_kind,p_dir,p_body,q_hi,a_hi,b_hi,c_hi,d_hi,q_en,a_en,b_en,c_en,d_en,ans,source,is_pyq,years
```

| कॉलम | ज़रूरी? | क्या भरना है | उदाहरण |
|---|---|---|---|
| `exams` | ✅ | कौन-सी परीक्षा | `utet1` या `utet1,ctet1` |
| `section` | ✅ | पाँच में से एक | `cdp` `hindi` `english` `math` `evs` |
| `topic` | ✅ | नीचे दी सूची से **बिल्कुल वही शब्द** | `समावेशी शिक्षा` |
| `difficulty` | ⬜ | 1 आसान, 2 मध्यम, 3 कठिन | `2` |
| `pid` | ⬜ | गद्यांश की आईडी (हो तो) | `P001` |
| `p_kind` | ⬜ | गद्यांश का प्रकार — सिर्फ़ पहली पंक्ति में | `prose` / `poem` / `chart` |
| `p_dir` | ⬜ | «निर्देश :» वाली लाइन — सिर्फ़ पहली पंक्ति में | `निर्देश : निम्नलिखित…` |
| `p_body` | ⬜ | पूरा गद्यांश — सिर्फ़ पहली पंक्ति में | `परिश्रम ही सफलता…` |
| `pseq` | ⬜ | गद्यांश में क्रम | `3` |
| `q_hi` | ✅ | हिन्दी प्रश्न | `थॉर्नडाइक ने कितने नियम दिये ?` |
| `a_hi` `b_hi` `c_hi` `d_hi` | ✅ | चार विकल्प हिन्दी में | `दो` `तीन` `चार` `पाँच` |
| `q_en` | ⬜ | अंग्रेज़ी प्रश्न (न हो तो खाली) | `How many laws...` |
| `a_en` `b_en` `c_en` `d_en` | ⬜ | चार विकल्प अंग्रेज़ी | `Two` `Three` `Four` `Five` |
| `ans` | ✅ | **0=पहला, 1=दूसरा, 2=तीसरा, 3=चौथा** | `1` |
| `source` | ⬜ | कहाँ से आया | `CTET Jul-2024 Q17` |
| `is_pyq` | ⬜ | असली पुराना प्रश्न है? 1 या 0 | `1` |
| `years` | ⬜ | किन वर्षों में आया | `2023,2025` |

### ⚠️ सबसे ज़्यादा होने वाली गलती
`ans` में **1,2,3,4 मत लिखना**। गिनती **0 से** शुरू होती है:

```
पहला विकल्प सही  → ans = 0
दूसरा विकल्प सही → ans = 1
तीसरा विकल्प सही → ans = 2
चौथा विकल्प सही  → ans = 3
```

### एक असली पंक्ति कैसी दिखती है

```csv
utet1,cdp,अधिगम सिद्धांत,2,,,थॉर्नडाइक ने अधिगम के कितने मुख्य नियम दिये ?,दो,तीन,चार,पाँच,How many chief laws of learning were given by Thorndike ?,Two,Three,Four,Five,1,UTET 2024 Q12,1,2024
```

**अगर प्रश्न में कॉमा हो** तो उसे दोहरे उद्धरण में डालो:
```csv
utet1,evs,प्रदूषण,2,,,"ताजमहल, आगरा को सबसे ज़्यादा क्या नुकसान पहुँचाता है ?",जल,वायु,ध्वनि,मृदा,,,,,,1,,0,
```

## 4 · 🤖 तैयार प्रॉम्प्ट — कॉपी करो और किसी भी AI में पेस्ट करो

### प्रॉम्प्ट A — किसी नए AI को प्रोजेक्ट समझाने के लिए

```
मैं UTET और CTET परीक्षा के लिए एक मॉक-टेस्ट ऐप बना रहा हूँ।

मेरे पास एक question bank है जो GitHub पर CSV फाइलों में रहता है।
हर प्रश्न पर एक "p_score" होता है जो बताता है कि वो प्रश्न असली
परीक्षा में आने की कितनी संभावना रखता है। यह score पिछले 3 साल के
असली पेपरों के विश्लेषण से निकला है।

CSV का फॉर्मेट यह है (यही क्रम, यही कॉलम नाम):
exams,section,topic,difficulty,pid,pseq,p_kind,p_dir,p_body,
q_hi,a_hi,b_hi,c_hi,d_hi,q_en,a_en,b_en,c_en,d_en,ans,source,is_pyq,years

- section: cdp | hindi | english | math | evs
- ans: 0=पहला विकल्प, 1=दूसरा, 2=तीसरा, 3=चौथा
- is_pyq: 1 अगर यह असली पुराना प्रश्न है, 0 अगर नया बनाया
- years: किन वर्षों में आया, जैसे 2023,2025

मैं तुम्हें आगे काम बताऊँगा। अभी सिर्फ़ "समझ गया" कहो।
```

---

### प्रॉम्प्ट B — ⭐ सबसे ज़रूरी: पुराना पेपर → CSV

> यही वो प्रॉम्प्ट है जिससे तुम्हें CSV "कहीं से लानी" नहीं पड़ेगी।
> PYQ का टेक्स्ट पेस्ट करो, AI CSV बना देगा।

```
नीचे एक असली परीक्षा का प्रश्न-पत्र दिया है। इसे CSV पंक्तियों में बदलो।

नियम:
1. हेडर पंक्ति मत लिखना, सिर्फ़ डेटा पंक्तियाँ दो
2. कॉलम का क्रम बिल्कुल यह रहे:
   exams,section,topic,difficulty,pid,pseq,p_kind,p_dir,p_body,
   q_hi,a_hi,b_hi,c_hi,d_hi,q_en,a_en,b_en,c_en,d_en,ans,source,is_pyq,years
3. exams = utet1   (CTET का पेपर हो तो ctet1)
4. section इन पाँच में से चुनो:
   प्रश्न 1-30   → cdp
   प्रश्न 31-60  → hindi
   प्रश्न 61-90  → english
   प्रश्न 91-120 → math
   प्रश्न 121-150→ evs
5. topic — नीचे दी सूची में से बिल्कुल वही शब्द चुनो, नया मत बनाओ:
   [यहाँ धारा 5 की टॉपिक सूची चिपकाओ]
6. ans = 0,1,2,3 (0 मतलब पहला विकल्प सही)
   अगर आंसर-की नहीं दी है तो अपने ज्ञान से सही उत्तर तय करो
7. is_pyq = 1  (क्योंकि यह असली पुराना प्रश्न है)
8. years = पेपर का साल, जैसे 2024
9. source = परीक्षा का नाम + प्रश्न संख्या, जैसे "UTET 2024 Q17"
10. जिस प्रश्न में कॉमा हो, उस खाने को "दोहरे उद्धरण" में डालो
11. अंग्रेज़ी वाला हिस्सा न हो तो q_en से d_en तक खाली छोड़ दो (सिर्फ़ कॉमा)
12. गद्यांश वाले प्रश्नों के लिए pid में P001, P002… और pseq में 1,2,3,4,5 डालो
13. कुछ समझ न आए तो उस प्रश्न को छोड़ दो, गलत मत भरो

आउटपुट सिर्फ़ CSV पंक्तियाँ, कोई व्याख्या नहीं।

प्रश्न-पत्र:
---
[यहाँ PYQ का टेक्स्ट पेस्ट करो]
```

> इसी से "unlimited" मॉक बनते हैं।

```

5. source में लिखो: variant-of:[मूल प्रश्न का source]

मूल प्रश्न:
[यहाँ प्रश्न पेस्ट करो]
```

## 6 · प्रायिकता का पूरा गणित

> यह वो formula है जिससे 29-सितम्बर के पेपर में 5–10 प्रश्न मिले।
> किसी भी AI को यह दो, वो दोबारा बना देगा।

### चरण 1 — साल का भार
```
2023 → 0.20      (पुराना, कम वज़न)
2024 → 0.30
2025 → 0.50      (नया, सबसे ज़्यादा वज़न)
```

### चरण 2 — concept की संभावना
```python
k = कितने साल यह concept आया
n = कुल साल (= 3)

laplace = (k + 1) / (n + 2)
lam     = उन वर्षों के भार का जोड़
recency = 1 - exp(-2.2 * lam)

concept_score = 0.55 * laplace + 0.45 * recency
```

### चरण 3 — टॉपिक की संभावना
```python
topic_score = (टॉपिक कितने साल आया + 1) / (3 + 2)
```

### चरण 4 — अंतिम अंक
```python
p_score = 0.60 * concept_score + 0.40 * topic_score
अगर असली PYQ है →  p_score = min(1.0, p_score * 1.15)
```

### नतीजा
| स्थिति | p_score |
|---|---|
| तीनों साल आया | **0.84** 🔥 |
| पिछले 2 साल | **0.70** 🔥 |
| 2023 + 2025 (चक्रीय) | 0.68 ⭐ |
| सिर्फ़ 2025 | 0.52 ◐ |
| सिर्फ़ 2023 | 0.38 ○ |
| बिल्कुल नया | 0.11 ○ |

### मॉक बनाते समय
प्रश्न `p_score^3` के भार से चुने जाते हैं (random नहीं) — इसलिए
ऊँची संभावना वाले प्रश्न लगभग हमेशा आते हैं।
