❓ सारे Doubts — एक-एक करके

1. सारे सेक्शन एक फाइल में, या हिन्दी अलग / English अलग / CDP अलग ?
✅ एक पेपर = एक फाइल। उसी एक फाइल में पाँचों सेक्शन डाल दे। सेक्शन के हिसाब से मत बाँट।

क्यों? क्योंकि रोबोट फाइल का नाम देखता ही नहीं — वो section कॉलम देखता है। अभी टेस्ट करके दिखाया : एक ही फाइल में cdp + math + hindi + evs डाले, और सब अपनी-अपनी जगह चले गए।

# एक फाइल में सब कुछ — बिल्कुल सही है
q_ctet_jul2024.csv
   पंक्ति 1   → section=cdp
   पंक्ति 31  → section=hindi
   पंक्ति 61  → section=english
   पंक्ति 91  → section=math
   पंक्ति 121 → section=evs

नतीजा : cdp 61 · hindi 62 · math 61 · evs 61  ✅ सब सही जगह
व्यावहारिक फ़ायदा : AI तुझे एक पेपर के पूरे 150 प्रश्न एक साथ देगा। तुझे उन्हें काट-काटकर 5 फाइलों में बाँटना नहीं पड़ेगा — सीधा एक फाइल में चिपका दे।
जो 5 फाइलें पहले से हैं (q_cdp.csv, q_hindi.csv…) उन्हें छूना ही मत। वो पुराने 300 प्रश्न हैं, वैसी ही पड़ी रहने दे।

3. हर नई फाइल में header लाइन डालनी है ?
✅ हाँ। हर फाइल की पहली लाइन header होनी चाहिए।

TEMPLATE.csv की पहली लाइन कॉपी करके हर नई फाइल में सबसे ऊपर चिपका दे। बस इतना।

Header भूल गया तो तेरा पहला प्रश्न गायब हो जाएगा (रोबोट उसे header समझ लेगा)।
4. गद्यांश (comprehension) वाले प्रश्न कैसे डालूँ ? — ये सबसे उलझन वाला था
✅ अब आसान कर दिया — गद्यांश उसी CSV में लिख, अलग फाइल की ज़रूरत नहीं।

5. एक फाइल में कितने प्रश्न डाल सकता हूँ ?

फाइल 2,000 पंक्तियों से बड़ी हो जाए तो Excel धीमा लगने लगता है — तब नई फाइल बना ले।

7. Excel में हिन्दी टूटी-फूटी दिख रही है
✅ फाइल UTF-8 में सेव कर।
  • Excel : File → Save As → टाइप में «CSV UTF-8 (Comma delimited)» चुन
  • Google Sheets : अपने-आप UTF-8 होता है — सबसे सुरक्षित, यही इस्तेमाल कर
  • Notepad : Save As → Encoding में UTF-8
सबसे आसान तरीका : AI से CSV लेकर सीधे GitHub की वेबसाइट पर पेस्ट कर दे। Excel खोलने की ज़रूरत ही नहीं — GitHub हमेशा UTF-8 में सेव करता है।
8. आंसर-की नहीं है, तो ans में क्या डालूँ ?
✅ AI से तय करवा ले — प्रॉम्प्ट B में ये लिखा ही हुआ है।

फिर प्रॉम्प्ट E से किसी दूसरे AI से जँचवा ले। दोनों का जवाब एक हो तो लगभग पक्का सही है।

गलत उत्तर सबसे बड़ा नुकसान करता है — छात्र गलत चीज़ रट लेता है। जहाँ शक हो, वो प्रश्न छोड़ दे।
9. गलत प्रश्न डल गया, कैसे हटाऊँ ?
✅ CSV में से वो पंक्ति मिटा दे और commit कर दे। बस।

रोबोट हर बार सब कुछ दोबारा बनाता है, इसलिए हटाया हुआ प्रश्न अगले अपडेट में ऐप से भी चला जाएगा।

पूरी फाइल गलत हो गई? फाइल ही डिलीट कर दे — इसीलिए एक पेपर = एक फाइल रखने को कहा था।

11. GitHub पर फाइल डालूँ कैसे ? मुझे git नहीं आता
✅ git सीखने की ज़रूरत नहीं — सब ब्राउज़र से हो जाएगा।
  1. अपने repo पर जा → content फोल्डर खोल
  2. ऊपर «Add file» → «Create new file» दबा
  3. नाम लिख : q_ctet_jul2024.csv
  4. बड़े खाने में header + AI वाली CSV पंक्तियाँ पेस्ट कर
  5. नीचे हरा «Commit changes» दबा
  6. Actions टैब पर जाकर हरा ✅ आने का इंतज़ार कर (1 मिनट)
पुरानी फाइल में जोड़ना हो तो : फाइल खोल → ✏️ पेंसिल दबा → सबसे नीचे पेस्ट कर → Commit।
